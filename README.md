# App Releases

Public release repository for applications maintained in private source repositories.

Only installers, update packages, release notes, and other compiled/distributable release assets belong here. Application source code remains in the separate private repositories.

## Applications

- App Updater
- Autodesk Fusion Global Installer / Updater
- OpenLens
- Shipping Email

## Release tags

Each application uses a unique tag prefix so releases cannot collide:

- `app-updater-v<version>`
- `fusion-updater-v<version>`
- `openlens-v<version>`
- `shipping-email-v<version>`

Installers and built-in updaters should download only from this repository.
